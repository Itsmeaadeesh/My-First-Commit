## How to contribute (No command line needed!)

Follow these 7 quick steps directly on github.com:

1. **Click Fork** (top right corner of this page).
2. **In YOUR fork:** Click **Add file** ➔ **Create new file**.
3. **In the name box:** Type `contributors/` and then `your-github-username.txt` (example: `contributors/aarav-sharma.txt`).
4. **In the file box:** Type your display name on ONE single line (example: `Aarav Sharma`).
5. **Click Commit changes** (the green button at the top right).
6. **Click "Contribute"** ➔ **"Open pull request"** ➔ **"Create pull request"**.
7. **Wait ~30 seconds!** Our bot will automatically verify your file, merge it, and your piece will fly onto the live wall.

---

## Name Rules

- **Only one line** of text in the file.
- **1 to 30 characters** long.
- Use letters, spaces, dots, or hyphens (Unicode letters like Hindi/regional characters are allowed).
- No HTML tags, quotes, code, or symbols.

---

## Something went wrong?

If the bot leaves a comment with an error, don't worry! Here is what to check:

- **Wrong filename:** The filename must be `contributors/<your-username>.txt` where `<your-username>` is your exact GitHub username.
- **Extra files in PR:** Make sure you only created or edited that ONE single file inside `contributors/`. Do not edit README, workflows, or other files.
- **Forgot to fork:** Make sure you are working inside your own fork before creating the pull request.
- **Multiple lines or invalid characters in your name:** Keep your display name to a single line without quotes, HTML, or emojis.

Need help? Raise your hand and one of our event mentors will help you right away! 🚀
